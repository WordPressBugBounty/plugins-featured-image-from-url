== Description ==

### Remote featured images for WordPress and WooCommerce

**Featured Image from URL (FIFU)** lets you use externally hosted images as featured images for WordPress posts, pages, custom post types, and WooCommerce products and categories — without downloading the original files to your Media Library.

FIFU integrates with WordPress featured image functionality, allowing compatible themes and plugins to display external images.

FIFU has supported remote WordPress featured images since 2015.

### 10 Reasons to Use FIFU Free

1. **No uploads, no wasted storage:** Set featured images using external URLs without storing the original files on your server.
2. **WooCommerce support:** Use remote images for products and product categories.
3. **Automatic featured images:** Automatically assign featured images from your post content.
4. **Quick Editor:** Preview, replace, or remove featured images directly from WordPress content lists.
5. **Flexible image display:** Set default featured images, control their visibility, and avoid showing the same featured image twice.
6. **SEO and social sharing:** Support remote image metadata, structured data, and social sharing with compatible SEO plugins.
7. **Developer automation:** Manage featured images programmatically with WP-CLI and PHP functions.
8. **Unsplash image search:** Find and select images directly from WordPress.
9. **Replace broken images:** Automatically display a fallback image when an external image fails to load, without changing its saved URL.
10. **Optional image optimization:** Use compatible CDN delivery, responsive images, and lazy loading.

### Get started in three steps

1. Edit a post, page, or WooCommerce product.
2. Paste a public image URL into the FIFU featured image field.
3. Preview the image and save your changes.

For best results, use a direct image URL that is publicly accessible and allows external display. If an image does not load, check the URL and the source site's hotlink settings.

**Try it:** [Launch FIFU Free on TasteWP](https://tastewp.com/new?pre-installed-plugin-slug=featured-image-from-url&redirect=admin.php%3Fpage%3Dfeatured-image-from-url&ni=true) to set your first remote featured image.

Third-party integrations require the corresponding plugins and may depend on supported workflows.

== Installation ==

### Install from the WordPress dashboard

1. In WordPress, go to **Plugins > Add New**.
2. Search for **Featured Image from URL** or **FIFU**.
3. Install and activate the plugin.

### Install manually

1. Upload the `featured-image-from-url` folder to `/wp-content/plugins/`.
2. Activate FIFU from the WordPress **Plugins** screen.

Need help? Ask a question in the [official FIFU support forum](https://wordpress.org/support/plugin/featured-image-from-url/).

== Frequently Asked Questions ==

= What should I check if an image doesn't appear? =

Make sure the URL points directly to a publicly accessible image and that the source site allows external display. Also check FIFU's Hide Featured Media setting and clear page or CDN caches if needed.

= What happens when a remote image becomes unavailable? =

If the source temporarily stops serving an image, it can display again when the source is available. The URL remains saved, and FIFU Free's **Replace Not Found Image** option can show a fallback. If the source removes the image, you can update the URL.

= Why is the featured image displayed twice? =

This can happen when your theme already displays the featured image and FIFU is also configured to add it to post content. Check the theme and FIFU's post content options.

= Why don't my settings changes appear immediately? =

Your site or CDN may be showing a cached version of the page. Clear the relevant caches and reload the page to check the updated settings.

= Does FIFU download images into the Media Library? =

FIFU Free displays remote originals from their source URLs without downloading them. Optional CDN services can deliver resized images; FIFU PRO can download originals when local files are needed.

= Can remote images appear in Google Images? =

Yes. FIFU supports image metadata for search and social sharing, and publicly accessible remote images can appear in Google Images when eligible. Search engines decide what they index and how results rank.

= Is FIFU Cloud required to use CDN or lazy loading? =

No. FIFU's optional image-delivery settings do not require FIFU Cloud; Cloud is a separate service.

= Where can I manage image metadata? =

Go to **FIFU > Settings > Metadata** to generate, synchronize, or clean up metadata in batches.

= What happens if I uninstall FIFU? =

Themes and plugins that rely on FIFU to display remote featured images may no longer show them after FIFU is removed. Review FIFU's metadata cleanup options if you want to remove its stored data.

= Can I use featured videos with FIFU Free? =

No. Featured videos, featured audio, featured sliders, and remote media galleries are **FIFU PRO** features. FIFU Free supports featured images from URLs.
